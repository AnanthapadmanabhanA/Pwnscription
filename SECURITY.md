# Security Policy

## About this repository

Pwnscription is a documentation and resource project. It contains no running
application and no exploit code, so there is little to "exploit" here. Still,
if you spot something that could cause harm, let us know.

## Reporting an issue with the repo itself

If you find a problem with the repository (for example, a link that points to a
malicious site, content that could endanger patients, or anything that
shouldn't be here), please report it privately first:

- Use GitHub's **private vulnerability reporting** on this repo, or
- Contact the maintainer, [@AnanthapadmanabhanA](https://github.com/AnanthapadmanabhanA).

Please do not open a public issue for anything sensitive.

## Found a vulnerability in an actual medical device?

This repo is not the place to report it, and you should not post details here.
Use **coordinated vulnerability disclosure**:

1. Contact the device manufacturer through their security / PSIRT channel.
2. If needed, involve a coordinator such as CISA or your national CERT, or the
   relevant regulator (FDA in the US; BSI / BfArM in Germany; the competent
   authority in your EU member state).
3. Give time to remediate before any public disclosure. Never publish first.

See [docs/08-reporting-and-disclosure.md](docs/08-reporting-and-disclosure.md)
for the full process.
